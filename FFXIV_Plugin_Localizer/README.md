# 翻译插件的插件（FFXIV_Plugin_Localizer）

给其他 [Dalamud（卫月）](https://github.com/goatcorp/Dalamud) 插件的**界面文字**做运行时汉化的工具。

在 ImGui 文字绘制层把其他插件渲染出来的英文按对照表换成中文显示——**不改、不分发对方插件本体**，覆盖发生在渲染层。

## 功能
- **运行时替换**：钩子拦截 ImGui 文字，命中对照表即换中文；游戏原生 UI 走 Atk 层遍历
- **源码提取**：从插件公开 GitHub 仓库提取界面文案为候选（`[{原文,译文}]` 格式，可交外部 AI 翻译）
- **AI 机翻**：多服务商（DeepSeek / 智谱 / 通义 / Kimi 等 OpenAI 兼容端点），按平台自适应 max_tokens、超时自动拆批
- **词典管理**：本项目词典（我的翻译.json）跨插件通用；单词黑名单强制保留专名英文；wiki 官方术语优先
- **后台自动翻译**：可选地对新出现的未翻译英文自动机翻（带防抖门槛，防"看两眼就删"白烧额度）

## 使用
1. 在「AI 设置」填写你自己的 API Key（不填只能用内置翻译包/手动翻译）
2. 「源码提取」从 GitHub 提取候选文案（需能访问 GitHub，可配代理）
3. 「插件翻译」对候选机翻或手动补译，译文即时生效

## 隐私与安全
- **不收集、不上传任何数据**：除你自己配置的 AI 翻译接口外，不向任何第三方服务器发送信息
- **不修改对方插件文件**：所有汉化都是运行时内存层替换
- API Key 仅保存在本机插件配置目录，不随插件分发
